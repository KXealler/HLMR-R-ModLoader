чтобы открыть игру нужно нажать Играть в главном меню.

EN
Hello!
Installation method:
1. Extract the archive into the game folder.
2. Copy the data.win file into the Mods folder and rename it to "Original" (optional).

How to add and apply mods:
1. Copy the mod's .win file into the Mods folder and rename it however you want.
2. Run ModLoader.exe, open "Mods" in the main menu, and (if it's your first time) select the game folder.
3. A list of mods will appear. You need to select a mod and click the Load button.

Settings:
To change the language (RU/EN), click the square in the upper-left corner of the menu.
To change the game folder, open Settings in the main menu and specify the new path.

To launch the game, click Play in the main menu.
